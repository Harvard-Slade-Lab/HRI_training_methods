`main_analysis.ipynb` contains the main group-level performance analysis for our study. `variance_analysis.ipynb` contains the analysis relating variation and specificity to performance and training time. De-identified study data is stored in `/data`.

The folder `exo_study_analysis` contains the analysis notebook and corresponding data files for the analysis of the comparison ankle exoskeleton study.

All analyses were done using Python version 3.12.8. Requirements are listed in `requirements.txt`.
